# PriceVerify

PriceVerify es un proyecto fullstack TypeScript para consultar, comparar y gestionar precios.

## Stack sugerido
- Next.js
- TypeScript
- Tailwind CSS
- Vitest (para testing)
- Zod (validación)
- Vercel para despliegue

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
npm run type-check
```

## Estructura base

- `src/app` — páginas y rutas de la aplicación
- `src/components` — componentes reutilizables
- `src/lib` — utilidades y lógica compartida
- `data` — archivos JSON y esquemas
